# MINDTRACE — FULL-STACK BUILD PROMPT FOR REPLIT AI

## PROJECT IDENTITY
App Name: MindTrace
Concept: A dark premium cognitive journaling SaaS — users log thoughts, track emotional patterns, predict cognitive outcomes, and gain insights via AI.

---

## TECH STACK (NON-NEGOTIABLE)
- Framework: Next.js 14 (App Router)
- Language: TypeScript (strict mode)
- Styling: Tailwind CSS + CSS custom properties for theming
- UI: Custom components (no component library dependencies)
- Animation: Framer Motion
- Database: PostgreSQL via Prisma ORM
- Auth: NextAuth.js with Google OAuth provider
- File Storage: Cloudinary (evidence/image uploads)
- Voice: Web Speech API (SpeechRecognition + SpeechSynthesis)
- State: Zustand (client) + TanStack Query (server state)
- Forms: React Hook Form + Zod
- Realtime: Pusher (optional, for live sync)

## PRISMA SCHEMA

```prisma
model User {
  id        String    @id @default(cuid())
  email     String    @unique
  name      String?
  image     String?
  thoughts  Thought[]
  createdAt DateTime  @default(now())
}

model Thought {
  id          String     @id @default(cuid())
  title       String
  context     String
  emotion     String
  intensity   Int        @default(5)
  tags        String[]
  prediction  String?
  evidence    Evidence[]
  userId      String
  user        User       @relation(fields: [userId], references: [id])
  createdAt   DateTime   @default(now())
  updatedAt   DateTime   @updatedAt
}

model Evidence {
  id        String   @id @default(cuid())
  url       String
  type      String
  thoughtId String
  thought   Thought  @relation(fields: [thoughtId], references: [id])
}
```

- Chronological list of all thoughts

### Analytics (/analytics)

## API ROUTES (IMPLEMENT ALL WITH REAL DB CALLS)
GET  /api/thoughts         → prisma.thought.findMany({ where: { userId } })
POST /api/thoughts         → prisma.thought.create(...)
GET  /api/thoughts/[id]    → prisma.thought.findUnique(...)
PUT  /api/thoughts/[id]    → prisma.thought.update(...)
DELETE /api/thoughts/[id]  → prisma.thought.delete(...)
GET  /api/analytics        → aggregated stats from thoughts
GET  /api/timeline         → thoughts sorted by date with emotion metadata
DELETE /api/memory         → prisma.thought.deleteMany({ where: { userId } })

All routes must:
- Check session via `getServerSession(authOptions)`
- Return 401 if unauthenticated
- Return proper HTTP status codes
- Use try/catch with error responses
